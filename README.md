# Ajuste-Linear-Simples-ALS---C-culo-Num-rico
Cálculo Numérico | Ajuste de Curvas (Ajuste Linear Simples): Implementação em Python que calcula a melhor reta para uma série de pontos amostrados, compara seu desvio total (D) com duas retas aleatórias, gera a tabela de desvios e plota os pontos e as três retas no mesmo plano cartesiano.
